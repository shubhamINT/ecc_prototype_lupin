# Navigation and Filter Patterns

- `AdminDashboard` toolbar should not use left-side quick-filter chips (for example `IT Focus`, `Rajesh Drilldown`).
- Keep filtering controls in this order: search input, `All Departments` dropdown, `All Statuses` dropdown, then result count.
- Secondary screens launched from Admin actions (for example `Email Alerts`) should include a visible `Back to Dashboard` button at the top of the page body.
